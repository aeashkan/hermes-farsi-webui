# 🤖 Hermes Agent Persian Web UI (رابط وب فارسی هرمس)

یک رابط کاربری وب مدرن، راست‌چین (RTL) و سبک برای دستیار هوش مصنوعی **Hermes Agent** با قابلیت‌های پیشرفته مدیریت کانتکست، دستورات اسلش و **بدون هیچ‌گونه وابستگی خارجی (Zero Dependencies)**.

---

## ✨ ویژگی‌های کلیدی (Key Features)

* **🚀 صفر وابستگی خارجی (Zero Dependencies):** ساخته‌شده کاملاً با کتابخانه استاندارد پایتون (`http.server`, `sqlite3`, `subprocess`, `urllib`). بدون نیاز به اجرای هیچ دستور `pip install`!
* **🇮🇷 پشتیبانی کامل از زبان فارسی (Full Persian & RTL):** تایپوگرافی زیبا با فونت وزیرمتن (Vazirmatn)، رابط کاربری دارک مدرن و راست‌چین استاندارد.
* **📊 نمایشگر زنده کانتکست (Real-time Context Meter):** مشاهده زنده تعداد توکن‌های مصرف‌شده، ظرفیت پنجره کانتکست و درصد پر بودن حافظه مدل.
* **🗜️ فشرده‌سازی واقعی حافظه (`/compact`):** جمع‌بندی سابقه گفتگو و بایگانی پیام‌های قدیمی در دیتابیس جهت آزادسازی واقعی توکن‌ها و جلوگیری از کندی مدل.
* **⌨️ منوی هوشمند دستورات اسلش (Slash Autocomplete):** باز شدن خودکار پاپ‌آپ راهنما با فشردن کلید `/` و امکان انتخاب آسان دستورات با کلیدهای جهت‌نما یا ماوس.
* **🗂️ مدیریت پیشرفته نشست‌ها (Session Management):** امکان مشاهده تاریخچه گفتگوها، سوییچ بین نشست‌ها، حذف نشست‌ها و ایجاد گفتگوی تازه (`/new`).
* **⏱️ مهلت پاسخ‌دهی طولانی (Extended Timeout):** تنظیم تایم‌اوت ۳۶۰ ثانیه‌ای (۶ دقیقه) برای پاسخ‌دهی به پرامپت‌های سنگین تحلیلی و ابزارهای سیستم بدون قطعی ارتباط.
* **🌐 چندسکویی (Cross-Platform):** سازگاری و تشخیص خودکار مسیر دیتابیس هرمس روی ویندوز، لینوکس و macOS.

## 📋 پیش‌نیازها (Prerequisites)

1. **پایتون:** نسخه ۳.۹ یا بالاتر (Python >= 3.9)
2. **کلاینت هرمس:** نصب بودن ابزار خط فرمان Hermes Agent (`hermes` CLI) روی سیستم:
   ```bash
   # مستندات و راهنمای نصب هرمس:
   # https://hermes-agent.nousresearch.com/docs
   ```

## 🚀 راهنمای راه‌اندازی سریع (Quick Start)

### ۱. کلون کردن ریپازیتوری
```bash
git clone https://github.com/aeashkan/hermes-farsi-webui.git
cd hermes-farsi-webui
```

### ۲. اجرا (ویندوز / لینوکس / مک)

* **در ویندوز:** فقط کافیست روی فایل **`run.bat`** دابل‌کلیک کنید، یا در ترمینال اجرا کنید:
  ```cmd
  python app.py
  ```

* **در لینوکس / macOS:**
  ```bash
  chmod +x run.sh
  ./run.sh
  ```

مرورگر شما به‌صورت خودکار باز شده و به نشانی زیر هدایت می‌شوید:
👉 **`http://localhost:8181`**

---

## ⚙️ گزینه‌های خط فرمان (Command-line Options)

شما می‌توانید پورت و سایر تنظیمات را با سوئیچ‌های زیر تغییر دهید:

```bash
# تغییر پورت پیش‌فرض
python app.py --port 9000

# فعال‌سازی دسترسی از شبکه محلی
python app.py --host 0.0.0.0 --port 8181

# اجرا بدون باز کردن خودکار مرورگر
python app.py --no-browser

# اجرای تست خودکار سلامت سرور و APIها
python app.py --test
```

## 🛠️ دستورات اسلش پشتیبانی‌شده (Slash Commands)

دستورات زیر را می‌توانید مستقیماً داخل کادر چت بنویسید یا از دکمه‌های میانبر بالای صفحه استفاده فرمایید:

| دستور | عملکرد |
| :--- | :--- |
| **`/status`** | نمایش زنده مدل فعال، شناسه سشن، مصرف توکن و وضعیت سیستم |
| **`/context`** یا **`/ctx`** | گزارش ظرفیت کانتکست و درصد اشغال حافظه |
| **`/compact`** یا **`/compress`** | فشرده‌سازی عمیق حافظه چت و آزاد کردن توکن‌ها |
| **`/usage`** | آمار تفکیکی مصرف توکن‌ها و فراخوانی‌های دستیار |
| **`/new`** یا **`/reset`** | ریست و شروع یک نشست گفتگوی تازه |
| **`/clear`** | پاکسازی صفحه نمایش پیام‌ها |
| **`/model`** | مشاهده مدل فعال و راهنمای انتخاب مدل |
| **`/skills`** | مشاهده فهرست مهارت‌های تخصصی بارگذاری‌شده در هرمس |
| **`/tools`** | فهرست ابزارهای سیستمی و دسترسی‌های فعال |
| **`/help`** | نمایش راهنمای کامل فرامین |
